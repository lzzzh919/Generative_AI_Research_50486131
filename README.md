# Generative AI Research Project

## Project Overview

This repository contains research materials for the project **“Using Generative AI Tools: Boon or Bane.”** It is used to organise research data, documents, analysis files and reports while maintaining a clear version history.

## Repository Structure

* `Literature_Review/` – Journal articles, conference papers, books and reference notes.
* `Quantitative_Analysis/`

  * `Raw_Data/` – Original survey data.
  * `Cleaned_Data/` – Processed and anonymised survey data.
  * `Python_Scripts/` – Scripts used for quantitative analysis.
  * `Reports/` – Quantitative analysis reports.
* `Qualitative_Analysis/`

  * `Interview_Transcripts/` – Anonymised interview transcripts.
  * `Interview_Protocols/` – Interview questions and procedures.
  * `Consent_Forms/` – Information about participant consent documents.
  * `Visualisations/` – Qualitative data visualisations.
* `Drafts_and_Reports/` – Research proposals, draft papers and final reports.
* `Additional_Materials/` – Information sheets, photographs and other supporting materials.

## File Naming Convention

Files use clear and descriptive names with underscores between words. Dates should use the `YYYY-MM-DD` format, and different versions should be identified using version numbers such as `v01` and `v02`.

Example:

`2026-09-16_survey_analysis_report_v01.md`

## How to Navigate the Repository

Select the relevant folder according to the type of research material. Raw data should be kept separate from cleaned data, while scripts and reports should be stored in their corresponding analysis folders.

## Collaboration Guidelines

1. Pull the latest version of the repository before making changes.
2. Create a separate branch for significant changes.
3. Use meaningful commit messages that clearly describe the changes.
4. Do not overwrite another contributor’s work without discussion.
5. Create a pull request so changes can be reviewed before they are merged into the main branch.

## Data Privacy

This repository is private. Personal identifiers and confidential participant information must not be uploaded. Interview transcripts and research data must be anonymised, and consent forms must have appropriate access controls.
